# ✨ Gemma: Assistente de Documentos | Case Técnico Tarea
Este Estudo de Caso tem como objetivo o desenvolvimento de um sistema de RAG (Retrieval-Augmented Generation), capaz de consultar e utilizar informações extraídas de documentos PDF para responder perguntas em linguagem natural. O sistema foi desenvolvido como parte do case técnico do processo seletivo para estágio da empresa Tarea, com o intuito de desenvolver uma solução capaz de transformar dados não estruturados em uma base consultável por um modelo de LLM (Large Language Model).
